# Files hosted in this repository

These few documents are part of the Knowledge Arc, but their publishers' websites refuse downloads by script (or show a notice page first, or rebuild the file every few weeks, or offer it only through a file-sharing link), so `scripts/download.py` cannot fetch them reliably. They are kept here instead, at the same path they have on a drive (`hosted/<catalog folder>`), and `download.py` copies them from here, checked against the sha-256 in `catalog/catalog.csv`. Each was downloaded from the publisher's own site, in a browser, and checked page by page like every other item.

The US government works (CDC, US Navy) are in the public domain or approved for public release. The CMHC, Humane Slaughter Association, NatureScot and Compasito guides are copyrighted and free to download, with no statement allowing copies elsewhere: they are included under the project's decision to assume permission for free-to-download items (`CLAUDE.md`, Licences). A publisher who objects can ask for a file to be removed; the arc then lists it as a manual download.

The repository's MIT licence (`LICENSE`) does not apply to these files: each stays under its publisher's terms, as listed above.

To add a file here: it must be a catalog row whose source blocks scripts, saved at `hosted/<its catalog folder>`, with its `sha256` filled in the catalog. `tests/test_download.py` checks that every file here matches its row and is listed above.
